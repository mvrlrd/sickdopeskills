## Статус: заморожен

Эта версия больше не развивается. Игра переписывается с нуля на **Godot 4 (GDScript)** в отдельном
репозитории **`sickdopeskills-godot`**.

Причина: цель — выпустить игру на **iOS и Android**, а эта версия её не закрывает. Модуль `ios`
удалён, возврат означал бы отдельный MobiVM-бэкенд со своим лаунчером; из 2800 строк кода около
920 — самодельный мини-фреймворк (`Base2DScreen`, `Sprite`, `Rect`, `SpritesPool`, `MatrixUtils`),
то есть ровно то, что движок даёт даром.

Рефакторинг архитектуры остановлен после тикета 06 сознательно. Его ценный продукт уже извлечён:
[docs/GLOSSARY.md](docs/GLOSSARY.md) — дословная спецификация правил игры (три предиката коллизий,
система координат, начисление очка, асимметрия красный/синий, полный список магических чисел),
которая и служит спекой для переписывания. Тикеты 07–17 помечены `wont-do`.

Эта ветка остаётся **живым эталоном для сверки ощущения**: собирается, запускается и играется.
Порт сверяется с ней бок о бок — ускорение, средний счёт за 10 заездов, плотность ёлок.

## Точка откака

[docs/SMOKE-CHECKLIST.md](docs/SMOKE-CHECKLIST.md) целиком. Геймплей на всём рефакторинге заморожен
1:1, поэтому любое расхождение проверяется откатом:
